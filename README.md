# TerritoryPulse

End-to-end demo app for Salesforce Financial Services Cloud.

## Purpose
- Wholesaler dashboard: accounts, pipeline, recent activity
- Customer view: relationship snapshot for Experience Cloud or record pages
- Operations quick view: territory performance, attainment, and activity summary

## Structure
- force-app/main/default/classes/
- force-app/main/default/lwc/

## Notes
This repo is a demo starter. You will need to adjust object/field names to match your FSC org.
